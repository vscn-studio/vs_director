FontSettings (神麤詭末 / scgm0)
Copyright (c) 2024 神麤詭末
Source: https://github.com/scgm0/FontSettings
Reference revision: d411c7dca871f0ea78c4b47be5b93ac73d4f1ee5
License: MIT; full text: FontSettings-MIT.txt.
DirectorImGuiTextFont.cs adapts the ImGui font synchronization workflow from
FontSettings/ImGuiCompat.cs: preserve locale glyph coverage and restore fonts
when the renderer uploads a rebuilt atlas. Director merges missing glyphs
into the live default without clearing the shared atlas or FontManager cache.
FontSettings retains font selection and rebuild ownership when installed.
Missing characters are supplied by locally installed system fonts. No system
font files or CJK font resources are redistributed in the mod package.
Its settings UI, system-font collection and other compatibility patches are
not included; FontSettings is optional and its assembly is not bundled.

Particle editor parameter groups, recursive native JSON editing and camera-facing
preview design reference Utils/ParticleEffectsManager.cs and
Utils/PreviewParticleSystem.cs. Client-only block/item replacement also references
Integration/ParticleRuntimePatches.cs at the revision above. The adaptation targets
the Vintage Story 1.22.3 AdvancedParticleProperties JSON contract, including random
distributions, lifecycle evolution, secondary/death providers and runtime context.
DirectorCreationParticleResources.cs, DirectorCreationWorkspace.AdvancedParticles.cs,
DirectorCreationParticleSimulation.cs and DirectorCreationRenderer.Particles.cs
independently implement resource scanning, restoration, deterministic fixed-step

replacement. No InGameDevTools runtime is bundled. The MIT notice above is retained.

and native lifetime/size units in Utils/PreviewParticleSystem.cs. The explicit
reference-fuel fire recipe in DirectorParticlePreparation.cs follows the behavior
of Vintage Story BEBehaviorBurning.onAsyncParticles/RandomBlockPos; no game
behavior is executed by browsing or imported-effect simulation. The reference
recipe is labelled and does not reproduce all live fuel/face/weather conditions.
Validation uses the installed Vintage Story 1.22.7.0 assemblies as well as the
1.22.3 JSON/API reference. Runtime/unknown shader fields remain export-only where
indicated by the editor; unsupported native application is rejected.

Fieldwright (Jeffrey Lueken / Venah), via Buildwright
Reference: local VS_BuildWright revision 9b15446cd4049a4b0f86299ee57688ba80580b53.
Fieldwright license: MIT; full text: Fieldwright-MIT.txt.
Buildwright original code shares this project's author and is covered by ../LICENSE.
Adapted Core/BlueprintModel.cs, Core/BlueprintCodec.cs, Client/RegionCapture.cs,
Client/BlockEntityCapture.cs and Client/BuildwrightGhostMesh.cs into
src/Blueprints/Adapted/. BlueprintFluidMesher.cs adapts the isolated chunk
geometry workflow from Client/BlueprintTerrainProjection.cs. Fieldwright notices
are retained in these files. Director independently integrates project-owned
blueprint assets, cached resource browsing, transforms, particle child objects,
standalone orbit preview and FFmpeg GIF/APNG export. Structure editing, slicing,
growth/material layers, edge particles, deterministic visual physics and grouped
structure timelines are independent Director implementations. No Buildwright mod system,
server placement or world mutation code is invoked. The optional compatibility
bridge uses an already installed Buildwright assembly; none is bundled.
